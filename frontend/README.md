# Фронтенд портфолио «Зеелиг»

Статический фронтенд без сборщика: `index.html`, `styles.css`, `config.js` и `app.js`. Изображения шапки, фона сайта и портрет для секции «Обо мне» находятся в `assets/images/`. Замените их, сохранив имена, либо поправьте пути в CSS.

## Запуск

1. Откройте каталог `frontend` через HTTP-сервер, например Live Server в VS Code. Не открывайте страницу через `file://`.
2. По умолчанию используется опубликованный API `https://portfolioz-backend-zeelig.msk1.amvera.tech/api`; адрес и category slug можно изменить в `config.js`. Для локального Strapi запустите в каталоге `backend` команду `npm run develop` и укажите в конфигурации `http://localhost:1337/api`.
3. Опубликуйте категории, подкатегории, теги и работы в Strapi.

## Публикация фронтенда

Фронтенд — чистая статика, установка зависимостей и сборка не нужны. В отдельном сервисе Amvera отдавайте содержимое каталога `frontend` через статический веб-сервер, используя `index.html` как стартовую страницу. При публикации должны быть доступны также `config.js`, `app.js`, `styles.css` и каталог `assets`.

## Интеграция Strapi

Фронтенд подключён к имеющимся API-моделям проекта:

- **Category** (`categories`): `Name`, relation `subcategories`.
- **Subcategory** (`subcategories`): `Name`, relation `category`, `tags` и `works`.
- **Tag** (`tags`): `Name`, relation `subcategories` и `works`.
- **Work** (`works`): `title`, `price`, `description` (Blocks), `image` (media), relation `tags`.

Категории «Картины» и декоративное направление связываются по CMS-полю `Name`; кнопки вкладок — по имени подкатегории. После выбора подкатегории фронтенд находит её ID и загружает связанные теги и работы. На странице показываются только связанные с выбранной подкатегорией теги; по нажатию на тег работы фильтруются одновременно по `Work.tags` и выбранной подкатегории. В секции «Работы художника» можно перелистывать все опубликованные работы: на десктопе одновременно видны две работы с плавным сдвигом при переключении, на мобильном — одна. Полноэкранная кнопка открывает изображение поверх страницы, а нажатие на карточку открывает подробный просмотр и слайдер.

Чтобы фильтры показывали контент, в Strapi откройте Content Manager → Subcategories → нужную подкатегорию, выберите нужные записи в поле `Tags`, затем сохраните и опубликуйте подкатегорию. Это поле должно быть relation many-to-many с `Tag` (`Subcategory.tags`, обратная связь `Tag.subcategories`). У каждого выбранного тега также должны быть опубликованы записи. Чтобы по тегу показывались картины, привяжите опубликованные работы к тегу в поле `Work.tags` и к нужной подкатегории в `Work.subcategories`.

В Strapi-проекте публичны только GET-маршруты чтения для этих четырёх типов; создание, редактирование и удаление остаются защищёнными. CORS в настройках бэкенда разрешает запросы с любых доменов; при необходимости ограничьте его доменом фронтенда.
